# Elevation Media

**The Venue Advertising Network**

Elevation Media connects advertisers with customers inside real venues through two core products:

- Tap-to-Wi-Fi NFC media: free NFC wall/bar mounts for participating venues, with sponsored access journeys and measurable engagement.
- QR Coaster campaigns: campaign planning, design, print, venue placement, tracked QR destinations and advertiser reporting.

Advertiser campaign scales: Hyper Local, Multi-Area, Regional and National.

Social impact commitment: Elevation Media will donate 5% of profit to cancer research. Venue tap signage uses the line: **Each tap supports cancer research.**

## Deployment

This repository is the standalone source of truth for Elevation Media. Netlify publishes the repository root using `netlify.toml`.
